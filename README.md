# Augmented Reality - Year 11 Coursework

This is Year 11 coursework that was done around Augmented Reality for the Cambridge IT GCSE.

## Project requirements - by OCR

SDK: You must use an AR software development kit (SDK) to create your prototype. 
Deliverable: The main deliverable is a video recording of the working AR model prototype, either from a screen recording of a PC/laptop or a mobile device. 
Evidence: A web link or a QR code alone is not acceptable as proof of completion. 
Hardware: While not mandatory, you may need devices like webcams for testing and recording if your SDK doesn't support an on-screen preview. 

## Skills required - by OCR

Design: You will need to design an AR model prototype for a specific target audience. 
Creation: You will need to create the AR prototype using the chosen SDK. 
Testing and review: You must test and review the prototype, documenting the results and any changes made. 

Documentation: You will need to produce a report to go with the video evidence. 

## Overview

I decided to do this project in HTML, CSS and JS and on delivery of the coursework to OCR I delivered a Design Document, Test Plan, Overview Video and a Final Project Document.

This was overall a very good project to work on, and allowed me to expand my skills and try something new. I enjoyed working on this and would be willing to do work with Augmented Reality in future if the opportunity arises.
